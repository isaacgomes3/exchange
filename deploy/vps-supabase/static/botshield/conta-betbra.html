O Cookie da exchange costuma ser HttpOnly (não aparece no console). O jeito mais fácil é exportar um HAR e capturar aqui:

  1. Chrome logado na exchange → F12 → Network → filtro mexchange-api
  2. Botão direito num pedido → Copiar → Copiar como cURL
  3. Cole o cURL na caixa abaixo (ou arraste um arquivo .har)
