Token de Aplicativo Externo (recomendado)

Na BetBra: conta → Aplicativos Externos. Apps como BOT/SOFTWARE;LAYBACK já têm permissão de apostar offline. Se a BetBra mostrar token / session / API key ao criar ou reautorizar o app, cole abaixo — é o caminho mais estável na VPS.

  1. Abra Aplicativos Externos na BetBra (não clique no X — isso revoga)
  2. Crie/reautorize um app de bot, ou use o token do LAYBACK se tiver
  3. Cole o token aqui → Salvar → Testar sessão

O X na lista de apps é só “revogar”. Mantenha o LAYBACK ACTIVE. Se não aparecer token na tela, use o código do e-mail ou o Cookie abaixo.

Sessão do navegador (quando a VPS pede device)

O Cookie da exchange costuma ser HttpOnly (não aparece no console). O jeito mais fácil é exportar um HAR e capturar aqui:

  1. Chrome logado na exchange (Fulltbet ou BetBra) → F12 → Network → filtro mexchange-api
  2. Botão direito num pedido → Copiar → Copiar como cURL
  3. Cole o cURL na caixa abaixo (ou arraste um arquivo .har)
Ou arraste o arquivo .har aqui

Cookies ficam criptografados. Expirem quando você sair da BetBra. Depois de salvar, use Testar sessão — precisa ver accountId antes do place. Cookie do Chrome costuma falhar no IP da VPS.

Salvar login e senha

Use o e-mail/usuário e a senha da sua conta na BetBra / Mexchange. A senha nunca é exibida de volta — só confirmação de que está salva.

Armazenamento AES-GCM no servidor (exchange_connections). Não aparece no app nem no admin ArbiShield — só em botshield.arbishield.app.
