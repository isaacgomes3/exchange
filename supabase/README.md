# ArbiShield — arbishield.app

Banco e Auth self-hosted na VPS (same-origin):

```env
NEXT_PUBLIC_SUPABASE_URL=https://arbishield.app
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

BetBra (pré-live / odds — servidor na VPS com IP BR):

```env
MEXCHANGE_BOT_USER_AGENT=BOT/SOFTWARE;ArbiShield;1.0
MEXCHANGE_BIAB_LANGUAGE=PT_BR
```
